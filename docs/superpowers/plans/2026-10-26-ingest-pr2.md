# Ingest freshness PR 2 (`feat/ingest-freshness-honest-badge`) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The freshness badge, `/api/v1/ingest/health` and the daily workflow all judge staleness the same way, on the server, per source refresh policy, so IC3 (static annual reports) never reads as stale and economics refreshes monthly.

**Architecture:** A registry in `services/ingest_sources.py` maps each source to `scheduled` or `static`. `ingest_catchup.py` gains `source_is_stale()` (static → never stale) used by `get_ingest_health`, `get_ingest_freshness` and `select_sources`. The frontend renders the server's `stale` and `refresh_policy` instead of its own 24 h rule; the workflow reads the same fields instead of hardcoded thresholds.

**Tech Stack:** FastAPI, SQLAlchemy async, pytest + pytest-asyncio; React + TypeScript, Vitest + Testing Library; GitHub Actions (bash, curl, jq).

**Spec:** `docs/superpowers/specs/2026-10-25-ingest-freshness-design.md`, section 5 "PR 2" (2a–2e). Section 6 is decided. Section 8 answered by Arlo on 2026-10-26: **8.2 IC3 is `static`; 8.3 economics is scheduled `"0 3 1 * *"` with `INGEST_STALE_HOURS_ECON = 840`.**

> Changed after the final review: economics now runs daily (`"0 3 * * *"`) so a missed or failed run heals within 24 h. The final review also added a `disabled` effective policy (empty schedule) and made a never-succeeded static source stale. Remaining mentions of the monthly schedule below are historical.

**Stacking:** branched from `origin/fix/ingest-self-healing` (PR #233, open). Draft PR targets `main` with a "stacked on #233" banner; after #233 squash-merges, `git rebase --onto origin/main 5fd7f9b` (PR 1's head after the test-clock fix).

## Global Constraints

- Policy registry: `{"nvd": "scheduled", "cisa_kev": "scheduled", "epss": "scheduled", "economics": "scheduled", "ic3": "static"}`.
- A `static` source is never stale and does not affect `healthy` (neither staleness nor consecutive failures).
- `INGEST_STALE_HOURS_IC3` stays in config (unused by the verdict while IC3 is static).
- `INGEST_SCHEDULE_ECONOMICS = "0 3 * * *"` (daily; changed from `"0 3 1 * *"` after the final review), `INGEST_STALE_HOURS_ECON = 840`.
- Catch-up never selects a `static` source for staleness. Seeding an empty table still applies (design 1b seed path; IC3's only data path is its seed). Ruling made here, see Review Focus 2.
- No second staleness implementation: reuse `hours_since()`, `is_stale()`, `stale_thresholds()`.
- Every ingestion goes through `_run_ingestion`.
- Static label copy, exactly: `IC3: static (2021–2025 annual reports)` (en dash).
- Freshness poll: 5 minutes, paused while `document.hidden`; window event name `freshness:refresh`.
- `PipelineHealthTab` dispatches `freshness:refresh` only from the 2 s `refreshTimerRef` callback and the running→idle transition, never synchronously after the trigger.
- Workflow: no hardcoded source list or thresholds; every `uses:` SHA-pinned (this PR adds none); `BACKEND_URL` never echoed; printed fields sanitised.
- `render.yaml`: comments only. Public repo; no attribution.
- Backend gate: `WT=C:/dev/ht-ingest-pr2/backend bash C:/dev/Senior-Cybersecurity-Project/docs/superpowers/prompts/backend-gate.sh [target]`. Frontend gate in `frontend/`: `npm run lint`, `npx tsc --noEmit`, `npm test`, `npm run build`.

## Review Focus

1. **Old backend, new workflow.** If the workflow reaches production before the PR 2 backend deploys, items have no `refresh_policy`/`stale`. Expected: a source with `stale` not exactly `false` and policy not `"static"` counts as stale (IC3 goes red until the deploy lands, which is honest). Reviewer walks this by hand (Task 4).
2. **Static source with an empty table.** IC3 is static, but a fresh database has no IC3 rows. Expected: catch-up still seeds it; it is only never re-run for age. Pinned by `test_static_source_still_seeds_when_empty` (Task 1).
3. **Static source failing repeatedly.** Two failed IC3 runs must not flip `healthy`. Pinned by `test_health_static_source_ignored_for_healthy` (Task 1).
4. **Vacuous green.** A 200 with `{"sources": {}}` or only static sources must not pass the workflow. Expected: zero non-static sources = unusable body, keep polling, then fail. Reviewer walks this by hand (Task 4).
5. **Hidden tab and unmount.** No fetch while hidden; becoming visible fetches once and restarts the interval; unmount clears the interval, the listeners, and aborts the in-flight request. Pinned by `does not poll while hidden` and `refetches once when visible again` (Task 2).
